# Project 1 : Windows Security Monitoring Lab | Microsoft Azure, Microsoft Sentinet, KQL
•	Deployed a Windows VM in Azure and configured a data collection rule to send Windows security events through Azure Monitor Agent to a Log Analytics workspace linked to Microsoft Sentinel.

•	Reviewed Windows Security logs in Event Viewer and queried the SecurityEvent table using Kusto Query Language(KQL) to filter for the Administrator account and select relevant fields 

•	Configured a Sentinel workbook using a GeoIP watchlist and provided a query to map failed sign-ins (Event ID 4625) by source IP location and show the number of attempts from each location
